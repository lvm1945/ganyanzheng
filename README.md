## 二、摘要

**目的**：探究基于"肝开窍于目"理论的子午流注择时穴位按摩在干眼症病人临床护理中的应用效果。

**方法**：选取2023年1月—2025年9月我院眼科收治的162例干眼症病人，采用随机数字表法将病人分为对照组和观察组，每组81例。对照组实施常规护理，观察组在对照组基础上实施基于"肝开窍于目"理论的子午流注择时穴位按摩方案。比较两组病人干预前及干预4周后泪液分泌试验（Schirmer Ⅰ试验）、泪膜破裂时间（BUT）、眼表疾病指数（OSDI）评分。

**结果**：干预后，观察组Schirmer Ⅰ试验结果、BUT优于对照组，OSDI各维度评分低于对照组，差异均有统计学意义（P<0.001）。

**结论**：基于"肝开窍于目"理论的子午流注择时穴位按摩方案可有效改善干眼症病人泪液分泌、泪膜稳定性，减轻眼表疾病症状。

## 三、研究背景

干眼症是眼科常见疾病之一，近年来发病率呈显著上升趋势，严重影响病人的生活质量和视觉健康。现代社会生活节奏加快、长时间使用电子设备、处于空调环境以及较大的精神压力，都使干眼症的发病风险大大增加。

现代医学针对干眼症的治疗主要集中在补充泪液、抗炎、促进泪液分泌等方面：

- **人工泪液**：最常用的治疗药物，能在一定程度上缓解眼部干涩症状，但长期使用可能导致眼部依赖性，且部分病人对其效果并不理想。
- **抗炎药物**：如糖皮质激素和免疫抑制剂，虽能减轻眼部炎症，但存在一定副作用，限制其长期应用。
- **手术治疗**：泪道栓塞术等并非适用于所有病人，且存在一定手术风险。

中医理论在眼科疾病的防治中有着悠久的历史和独特的优势：

- **"肝开窍于目"理论**：阐述肝脏与眼睛之间的内在联系，认为肝脏气血充足、功能正常，则眼睛能够得到充分滋养，维持正常视觉功能；若肝脏出现气血亏虚、肝郁气滞等病理变化，就会直接影响眼睛的生理功能，导致干涩、视物模糊等症状。《黄帝内经》记载"肝受血而能视"，强调肝脏气血对眼睛视觉功能的重要性。现代医学研究也发现，肝脏的血液循环和代谢功能与眼部的营养供应密切相关，肝脏疾病病人往往会出现不同程度的眼部病变。
- **子午流注学说**：作为中医时间医学的核心内容，认为人体的气血在一天中会按照一定规律循环流注于十二经脉，每个经脉都有其气血旺盛的特定时间。在相应时间刺激特定穴位，能够调节人体的气血运行，增强穴位的治疗作用。这种时间医学理念与现代医学的生物钟理论相契合，提示可以利用人体自身的生理节律来提高治疗效果。

基于以上理论，本研究提出将"肝开窍于目"理论与子午流注学说相结合，制订相应择时穴位按摩方案并应用于干眼症病人的临床护理中——通过在肝经气血旺盛的特定时间按摩与肝脏和眼睛相关的穴位，期望调节肝脏的气血功能，改善眼部的血液循环和营养供应，从而达到改善干眼症相关症状的目的。

## 四、对象与方法

### 4.1 研究对象

选取2023年1月—2025年9月我院眼科就诊的162例干眼症病人作为研究对象。

**纳入标准**：

1. 符合《干眼临床诊疗专家共识（2020年）》中干眼症的诊断标准；
2. 年龄18~65岁；
3. 自愿参与本研究并签署知情同意书。

**排除标准**：

1. 合并其他严重眼科疾病；
2. 患有严重的全身性疾病；
3. 近1个月内使用过影响泪液分泌或眼部血液循环的药物；
4. 有精神疾病或认知障碍，无法配合治疗和评估。

采用随机数字表法将病人分为对照组和观察组，每组81例。两组病人一般资料比较，差异均无统计学意义（P>0.05），具有可比性。本研究经我院医学伦理委员会审批（审批号：CZYLS-2024061）。

### 4.2 干预方法

#### 对照组：常规护理

1. **健康教育**：向病人详细讲解干眼症的病因、症状、治疗方法和注意事项。发放健康教育手册，内容包括干眼症的预防知识、正确的用眼习惯等。定期组织健康讲座，邀请眼科专家为病人进行讲解，增强病人的自我保健意识。
2. **眼部护理**：指导病人正确使用人工泪液，告知使用频率和方法。保持眼部清洁，避免用手揉眼睛。为病人提供眼部清洁用品，如生理盐水、清洁棉球等。
3. **饮食指导**：鼓励病人多吃富含维生素A、C、E和叶黄素的食物，制订饮食方案，根据病人口味和饮食习惯进行调整。

#### 观察组：常规护理 + 子午流注择时穴位按摩方案

**（1）成立专项小组**

由1名护士长、1名眼科医生、4名护士和1名中医康复师组成。分工如下：

- **护士长（组长）**：制订干预方案、协调小组工作、监督方案实施等研究统筹工作；
- **眼科医生**：负责病人诊断、病情评估和治疗方案制订，确定按摩穴位、手法和强度；在按摩过程中定期复查，观察病情变化，及时调整治疗方案；
- **护士**：负责护理操作、病人日常管理和数据收集；
- **中医康复师**：精通中医理论和穴位按摩技术，负责穴位按摩的指导。

邀请中医专家对小组成员进行培训，内容包括"肝开窍于目"理论（理论内涵、子午流注学说的原理和应用）、子午流注学说（肝经气血旺盛的时间及选择此时进行穴位按摩的原理和优势）、穴位定位（采用人体模型与实际操作相结合，掌握睛明、攒竹、丝竹空、瞳子髎、肝俞、太冲等穴位的准确位置）和按摩手法（揉法、按法、推法、拿法）。培训采用理论讲解、实践操作和案例分析相结合的方式，并在按摩过程中对护士进行现场指导，纠正不规范手法。

**（2）择时理论：子午流注开穴计算**

小组成员检索中国知网、万方数据库、维普数据库、PubMed等中"肝开窍于目"理论、子午流注学说和穴位按摩治疗干眼症的相关文献，结合既往临床实践经验，组织多次小组会议讨论，制订方案。根据子午流注学说计算开穴：

```
元旦日干数 = [11 + 21N + 5M - (闰年为1/平年为0) - R] / 10 所得余数
元旦日支数 = [11 + 21N + 5M - (闰年为1/平年为0) - R] / 12 所得余数
其中 R = 15；M 为公元年数除以4所得的余数；N 为公元年数除以4所得的整数商

日干数 = [(元旦干数 + 天数 - 1) / 10] 所得余数
日支数 = [(元旦支数 + 天数 - 1) / 12] 所得余数

时支数 = [(日支数 - 1) × 12 + 时辰数] / 12 所得余数
时干数 = [(日干数 - 1) × 12 + 时辰数] / 10 所得余数
```

根据计算得出的干支，参照《纳干反克法表》找出对应穴位，进行穴位按摩。

**（3）按摩穴位**

睛明、攒竹、丝竹空、瞳子髎、肝俞、太冲等。

- **睛明、攒竹、丝竹空、瞳子髎**：为眼部周围穴位，可直接作用于眼部，促进眼部血液循环；
- **肝俞、太冲**：为与肝脏相关的穴位，可调节肝脏的气血功能，从根本上滋养眼睛。

**（4）按摩手法和强度**

采用揉法、按法、推法相结合的手法。睛明、攒竹、丝竹空、瞳子髎等穴位用指腹轻轻揉按，力度以病人感觉轻微酸胀为宜；肝俞、太冲穴位用拇指按压，力度稍大，以病人能耐受为度。每个穴位按摩时间为2~3 min，每次按摩总时间为15~20 min。

**（5）实施步骤**

根据子午流注取当日当时所开穴位进行按摩。协助病人取仰卧位，暴露按摩部位；按摩前护士先在病人的穴位处涂抹适量按摩油，以减少摩擦力，同时起到润滑和滋养皮肤的作用；按照 **睛明 → 攒竹 → 丝竹空 → 瞳子髎 → 肝俞 → 太冲** 的顺序进行按摩。

| 穴位 | 操作手法 |
| --- | --- |
| 睛明 | 用双手食指指腹轻轻揉按，先顺时针方向揉按1~2 min，再逆时针方向揉按1~2 min |
| 攒竹 | 用双手拇指指腹从眉头向眉梢方向轻轻推按，然后再用指腹揉按穴位 |
| 丝竹空、瞳子髎 | 用双手中指指腹轻轻揉按 |
| 肝俞 | 病人取俯卧位，护士用双手拇指按压穴位，同时进行上下推动 |
| 太冲 | 用拇指按压穴位，并进行旋转揉动 |

按摩过程中与病人沟通，了解感受，根据病人反应及时调整按摩手法和力度。**每天按摩1次，连续按摩4周。**

### 4.3 观察指标

| 指标 | 评估时点 | 具体方法 |
| --- | --- | --- |
| 泪液分泌情况（Schirmer Ⅰ试验） | 干预前、干预4周后 | 使用标准泪液分泌试纸，将试纸一端折叠后放置于下睑中外1/3交界处的结膜囊内，病人轻闭双眼，避免眼球转动。5 min后取出试纸，测量试纸被泪液浸湿的长度（mm） |
| 泪膜稳定性（BUT） | 干预前、干预4周后 | 荧光素钠染色后，使用裂隙灯显微镜观察泪膜破裂时间。让病人眨眼数次后保持睁眼状态，观察泪膜表面出现第1个干燥斑的时间，测量3次取平均值（s） |
| 眼表疾病症状（OSDI） | 干预前、干预4周后 | 量表包括视力相关功能、眼部不适症状和环境相关症状3个维度，共12个条目。每个条目计0~4分，总分0~48分，得分越高表示眼表疾病症状越严重（分） |

### 4.4 统计学方法

采用 SPSS 22.0 统计学软件进行数据分析。符合正态分布的定量资料以均数±标准差（x±s）表示，两组间比较采用独立样本 t 检验，组内干预前后比较采用配对样本 t 检验；定性资料以例数和百分比（%）表示，两组间比较采用 χ² 检验。以 P<0.05 为差异有统计学意义。

## 六、讨论

### 6.1 对病人泪液分泌的影响

干预后观察组 Schirmer Ⅰ 试验结果优于对照组，表明该按摩方案能更有效地促进泪液分泌。

- **现代医学角度**：穴位按摩可以刺激神经末梢，调节神经递质的释放，从而影响泪腺的分泌功能。
- **中医理论角度**：肝开窍于目，肝脏气血充足与否直接影响眼睛的滋养。肝脏气血亏虚时，眼睛得不到足够濡养，泪液分泌就会减少。本方案选取与肝脏相关的肝俞、太冲等穴位，在肝经气血旺盛时进行按摩，能够调节肝脏气血运行，使肝脏气血充足，从而为眼睛提供充足滋养，促进泪液分泌。

与单纯采用眼部穴位按摩治疗干眼症的研究相比，本研究效果更显著。原因可能在于：单纯的眼部穴位按摩仅作用于局部，而本方案不仅按摩眼部周围穴位，还通过刺激与肝脏相关的穴位，从整体上调节肝脏功能，从根本上改善泪液分泌的内在环境。此外，根据子午流注择时按摩相关穴位，可能更符合人体生物钟的节律，使神经调节更加精准和高效。

### 6.2 对病人泪膜破裂时间的影响

干预后观察组泪膜破裂时间长于对照组，说明该按摩方案能够有效提高泪膜的稳定性。泪膜稳定性对于维持眼睛正常生理功能至关重要，泪膜破裂时间缩短是干眼症的重要表现之一。

- 相关研究发现，按摩眼部周围穴位可以促进眼部血液循环，增加眼部营养供应，改善眼表微环境，从而提高泪膜稳定性。
- 中医认为，肝主疏泄，能够调节人体的气机和津液代谢。通过按摩肝俞、太冲等穴位调节肝脏的疏泄功能，有助于维持津液的正常代谢和分布，使泪液能够均匀地分布在眼表，从而延长泪膜破裂时间。

与采用药物治疗改善泪膜稳定性的研究相比，本按摩方案具有优势：药物治疗可能带来副作用，且长期使用可能产生耐药性；而穴位按摩是一种绿色、安全的治疗方法，通过调节人体自身的生理功能来改善泪膜稳定性。结合子午流注学说在特定时间进行按摩，可能进一步增强这种调节作用。

### 6.3 对病人眼表疾病症状的影响

干预后观察组在**视力相关功能**维度评分明显低于对照组，说明该按摩方案有助于改善病人的视力相关功能。

- 中医理论认为，眼睛的视觉功能依赖于肝脏气血的滋养。肝脏气血充足时，眼睛能够清晰视物。本方案通过调节肝脏的气血运行，为眼睛提供充足营养，从而改善视力相关功能，并从中医整体观念出发，同时关注眼部局部调节与肝脏功能调理。
- 现代医学研究表明，穴位按摩可以刺激视神经功能，促进神经传导，提高视觉敏感度。在特定时间按摩相关穴位，可能使这种神经调节作用更加明显。

干预后观察组**眼部不适症状**维度评分低于对照组，表明该方案能有效减轻病人的眼部不适症状（干涩、疼痛、瘙痒、异物感等）。中医认为这些症状与肝脏气血失调、肝郁气滞等因素有关，按摩肝俞、太冲等穴位可以疏肝理气，调节肝脏气血功能。与使用抗炎药物的研究相比，本方案具有无副作用、长期效果好的优点；抗炎药物虽能在短期内减轻炎症反应，但不能从根本上解决问题。相关研究证实，按摩眼部周围穴位可以促进眼部新陈代谢，加速炎症因子清除。

干预后观察组**环境相关症状**维度评分低于对照组，说明该方案能提高病人对环境的适应能力，减轻环境因素对眼睛的影响。干眼症病人在干燥、多风、强光等环境中症状往往加重。中医认为人体与外界环境是一个有机整体，肝脏功能与人体对外界环境的适应能力密切相关。通过按摩相关穴位调节肝脏功能，增强人体的整体调节能力。

## 七、小结

本研究结果显示，基于"肝开窍于目"理论的子午流注择时穴位按摩方案可有效改善干眼症病人泪液分泌、泪膜稳定性，减轻眼表疾病症状。该方案结合中医整体观念和时间医学理论，从根本上调节人体生理功能，为干眼症治疗提供了一种安全、有效的护理方法。
